# 00. 용어 — 같은 말을 같은 뜻으로

| 항목 | 값 |
|---|---|
| 문서 | 00-GLOSSARY |
| 작성일 | 2026-09-18 |
| 왜 있나 | 이 제품에서 용어가 흔들리면 **숫자가 아니라 모수가 틀린다.** 모수가 틀린 숫자는 검산으로 잡히지 않는다 |

---

## 1. 법

| 용어 | 뜻 | 주의 |
|---|---|---|
| **계약갱신요구권** | 임차인이 만기 **6개월 전부터 2개월 전 사이**에 갱신을 요구할 수 있는 권리(주택임대차보호법 제6조의3). 같은 주택에서 **1회 한정** | 관공서 신청 절차가 없다. 임대인에게 **도달**하면 성립한다 |
| **행사 기한** | 만기 −6개월 ~ −2개월 | 2020-12-10 이전 체결분은 −1개월 기준이 적용될 수 있다. 이 서비스는 **두 날짜를 모두 보여 주고 이른 쪽을 마감으로 안내**한다 |
| **5% 상한** | 증액은 약정 차임·보증금의 **20분의 1**을 넘지 못한다(제7조) | **갱신요구권을 행사한 갱신에만 적용된다.** 합의 갱신에는 적용되지 않는다 |
| **합의 갱신** | 양측 합의로 조건을 새로 정하는 갱신 | 5% 상한이 **없다**. 이 서비스가 두 집단을 나눠 보여 주는 이유가 이것이다 |
| **묵시적 갱신** | 아무도 통지하지 않아 전 임대차와 **동일 조건**으로 이어지는 것 | 인상이 없다. 임대인이 이미 만료 통보를 보냈다면 성립하지 않는다 |
| **초과 차액** | 제시 조건과 5% 상한액의 **차이** | **위법 금액이 아니다.** 갱신요구권을 행사했을 때의 상한과 실제 조건의 차이다. 화면에서 이 문장은 차액이 나오는 모든 자리에 붙는다 |

## 2. 데이터

| 용어 | 뜻 | 주의 |
|---|---|---|
| **원천** | 국토교통부 전월세 실거래가 4종 API(아파트·연립다세대·단독다가구·오피스텔) | 하나다. 다른 원천과 병합하지 않는다 |
| **스냅샷 / 기준일(asof)** | 자산을 만든 날. `dist/data/anchors.json` 의 `asof` | 화면 상단에 항상 뜬다 |
| **전세→전세 갱신** | `계약구분 = 갱신` 이고 종전·현 **둘 다 월세가 없는** 계약 | 이 서비스의 모든 분포가 이 모수다. 월세가 섞이면 보증금 단독 비교가 성립하지 않는다 |
| **행사 기록 있음** | 갱신 행의 갱신요구권 칸에 **양성 토큰**(`사용`)이 있는 것 | |
| **행사 기록 없음** | 갱신 행의 그 칸이 **비어 있는** 것 | 미행사로 읽지만 **근거 등급 B**다. 신고서 서식이 2지 택일이고 생산기관도 빈 값을 미사용으로 집계한다는 것이 근거이지, 직접 관측이 아니다 |
| **코호트** | 비교 대상 묶음. `유형 \| 자치구 \| 법정동 \| 단지 \| 면적대` | 단지 단계는 **아파트에만** 있다 — 원천이 단지 일련번호를 아파트만 준다 |
| **폴백 사다리 / 확장** | 표본(행사 기록이 없는 갱신) 3건을 만날 때까지 코호트를 넓히는 5단계 | 예외가 아니라 갱신 계약의 53.38%가 지나는 **상시 경로**다. 어느 단계의 숫자인지 화면에 적는다 |
| **모수** | 그 비율의 분모 | 값 옆에 항상 붙인다. 없으면 결함이다(02-SPEC DR4) |
| **앵커** | 서울 전체 상수. 코호트와 무관하게 고정된 비교 기준 | `anchors.json` 이 단일 출처다 |
| **면적대** | 전용면적의 10㎡ 하한 구간. `50-60` 은 50.00~59.99 | 단독·다가구는 전용면적이 아니라 **연면적**이다 |

## 3. 판정

| 용어 | 뜻 |
|---|---|
| **판정** | 코드가 산술로 내는 결론. LLM 이 관여하지 않는다 |
| **상위 X%** | 같은 코호트의 **행사 기록이 없는 갱신** 중 나보다 **크거나 같은** 계약의 비율(동률 포함). 행사 기록 있는 갱신은 5% 상한이 걸린 계약이라 섞지 않는다 |
| **정확히 +5.00%** | `20 × 증감액 = 종전 보증금`. **정수 비교로만 판정한다** — 실수 비교를 쓰면 이 무리가 초과로 샌다 |
| **자릿수 사고** | 0을 하나 더 치거나 덜 친 오류. 종전과 제시가 같은 배율이면 **인상률은 정상으로 보인다** — 비율 검사로는 못 잡는다 |
| **되묻기(M-11)** | 자릿수 사고로 보일 때 판정을 멈추고 확인받는 것. **버리기가 아니다** — 사용자가 맞다고 하면 그대로 판정한다 |
| **판정 불가** | 표본이 없어 결론을 내지 않는 것. **추정치를 만들지 않는다** |
| **결말 문장** | 모든 상태가 끝나는 방식. 결말 문장이 없는 분기는 "조용한 통과"이고, 조용한 통과가 이 서비스가 없애려는 실패다 |

## 4. 쓰지 않는 말

| 쓰지 않는다 | 대신 | 왜 |
|---|---|---|
| **미사용 / 미행사** | "행사 기록이 없는 갱신 계약" | 데이터가 말하는 것은 칸이 비었다는 사실뿐이다. "미사용" 은 해석을 사실처럼 쓴다. 코드의 금칙어 목록에 들어 있다(`_llm.js`) |
| **위법 / 무효 / 승소 / 권리가 있습니다** | 조문 원문과 링크 | 그 순간 법률 자문이 된다. 검증층이 걸러 낸다 |
| **없다 (검색 결과에 대해)** | "검색어와 날짜 기준 미발견" | 부재는 관측이 아니다 |
| **약 / 대략 / ~정도** (수치 앞) | 값 그대로 + 모수 | 정밀도를 흐리면 검산할 수 없다 |
| **평균** (분포 설명에) | 중앙값·백분위 | 이상치 하나가 평균을 죽인다. 실제로 `종전 4만원 → 48,500만원` 같은 행이 있다 |
| **예측 / 전망** | "신고된 결과" | 이 데이터는 결과이지 예측이 아니다 |
| **최적 / 최고 / 혁신적** | 측정값 | 형용사는 검증되지 않는다 |
