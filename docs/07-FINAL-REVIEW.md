# 07. 제출 직전 검토 — 갱신 기준선

| 항목 | 값 |
|---|---|
| 문서 | 07-FINAL-REVIEW |
| 검토일 | 2026-09-19 (같은 날 수정 반영 — §결함 처분 참조) |
| 대상 | HEAD `ca3f500` + 이 검토가 만든 문서 변경. 제품 코드는 손대지 않았다 |
| 성격 | **위험 기반 검토 기록이다. 보안 인증도, 전수 점검도, 취약점 부재의 증명도 아니다.** |
| 검토자 | 이 저장소를 만든 작업자 본인(자기 검토). **독립 검토가 아니다** |

이 문서는 결함 목록의 정본이다. 제품 동작을 바꾸지 않는다 — **이 검토에서 제품 코드·프롬프트·평가 기준·동결 해시를 고치지 않았다.**

**판정 기호**: `PASS` 확인했고 의도대로다 · `FAIL` 확인했고 어긋난다 · `UNVERIFIED` 이 검토 범위에서 확인하지 못했다 · `N/A` 해당하지 않는다(이유를 함께 적는다).

## 0. 검토 범위

### 본 것

| 표면 | 파일 |
|---|---|
| 서버리스 함수 3종 | `functions/api/_llm.js` · `parse.js` · `draft.js` |
| 브라우저 판정·입력 | `dist/assets/rules.js` · `dist/assets/app.js`(경계 지점만) |
| 배포물 | `dist/index.html` · `dist/_headers` · `dist/data/*` |
| 빌드·검사 | `scripts/build_assets.py` · `scripts/test_*.mjs` · `test_all.sh` |
| 공개 문서 | `README.md` · `docs/*.md` · `docs/assets/*.png` |
| 평가 증거 | 보존된 실행 기록(로컬, 저장소 밖 — `05-TEST` §10-5) |

### 보지 않은 것 (의도적으로)

- **라이브 보안 시험을 하지 않았다.** 배포본에 XSS·주입·부하·장애 주입을 시도하지 않았다. 심사 기간 서비스를 끊을 수 있고 이 작업의 권한 밖이다.
- **키 폐기·지출 한도 변경·호스팅 설정 변경을 하지 않았다.** 강등 레버의 전제는 여전히 미검증이다(§G).
- **의존성 스캐너를 설치하지 않았다.** 선언된 의존성이 0개라 스캔할 대상이 없다(§F).
- **새 모델 호출을 하지 않았다.** 평가 수치는 전부 2026-09-19 보존 기록에서 읽었다.

### G3 상세 — 강등 레버 전제 5건, 공식 문서 확인 (2026-09-20)

인수인계 §3 이 "배포 없이 쓸 수 있는 유일한 수단"이라 적은 레버의 전제를 제공자·호스팅 공식 문서로 확인했다.

| # | 전제 | 결과 | 근거 |
|---|---|---|---|
| 1 | 지출 한도에 **0** 을 넣을 수 있는가 | **문서에 없음** | OpenAI *Spend limits* 문서가 0 설정 가능 여부를 다루지 않는다. 콘솔에서 확인해야 한다 |
| 2 | 한도 도달이 **경고인가 차단인가** | **확인 — 설정에 따라 갈린다** | 문서가 둘을 구분한다. *Spend alert* 는 "Sends a notification; **API traffic continues**", *Hard spend limit* 은 "Affected API requests return a **`429`** error"(`organization_spend_limit_exceeded` / `project_spend_limit_exceeded`). **"월 한도 $5" 가 어느 쪽인지는 기록에 없다.** 또 "Enforcement is not instantaneous" — 전파 중 초과 사용이 처리될 수 있다 |
| 3 | 키 폐기가 **되돌려지는가** | **확인 — 되돌릴 수 없다** | OpenAI 헬프센터: 삭제된 키는 복구 불가, 새 키를 만들어 애플리케이션을 갱신해야 한다. 인수인계의 "되돌리기도 키 하나다"는 **틀렸다 — 편도다** |
| 4 | 시크릿 교체가 **기존 배포에 즉시 반영**되는가 | **문서에 없음** | Workers 는 `wrangler secret put` 이 "creates a new version … and **deploys it immediately**" 로 문서화돼 있으나 **Pages 는 그 서술이 없다.** 대시보드 흐름은 "Select **Deploy** to implement your changes", 바인딩 문서는 재배포를 요구한다. **"배포 없이 모델을 바꾼다"는 근거가 없다** |
| 5 | **대회 동결 규정**과 충돌하는가 | **확인 — 그런 규정이 없다** | 보관한 요강은 *제출 폼*이 마감 후 열람 전용이라 적고, 서비스에는 *심사 기간 접속 유지*만 요구한다. 서비스 수정·재배포를 금하는 조항은 없다. 이전 판이 "동결 규정"이라는 명사로 그 존재를 전제했던 것을 정정한다 |

**레버의 실제 모습.** ② 가 *Hard spend limit* 일 때만 429 → `callOpenAI` 가 던짐 → `E_UPSTREAM` → 수동 입력 폼으로 정상 강등된다(이 경로는 `test_verify.mjs` 의 "상류 500" 케이스가 고정). *Spend alert* 였다면 아무 일도 일어나지 않는다. **가장 먼저 할 일은 콘솔에서 한도의 종류를 확인하는 것이다.**
