# 갱신 기준선

전월세 계약 갱신을 앞둔 세입자가, 집주인이 제시한 조건이 **같은 조건의 실제 갱신 계약들 사이에서 어디쯤인지** 공개 실거래 데이터로 확인하고 다음 행동을 정하도록 돕는 웹 서비스.

판정은 코드가 한다. 언어 모델은 입력 문장을 계산 값으로 바꾸고 결과를 문장으로 옮기는 두 단계만 맡으며, 숫자를 만들지 않는다.

## 이 서비스가 답하는 것

- 제시받은 인상률은 같은 조건 갱신 계약 중 어디에 있는가
- 갱신요구권을 행사한 계약과 그렇지 않은 계약의 인상률 분포는 어떻게 다른가
- 지금 나가면 새로 구할 때 얼마를 더 내야 하는가
- 법이 정한 갱신 요구 기간에서 오늘은 어디인가

## 측정된 사실 (2026-09-18)

서울 2026년 전세→전세 갱신 계약을 공개 파일과 공개 API로 직접 계산했다. 월세가 섞인 계약은 보증금 단독 비교가 불가능해 제외했다.

| 구분 | 5% 초과 비율 | 상위 10% 인상률 |
|---|---|---|
| 갱신요구권 행사 기록 있음 | 0.41% | 5.00% |
| 행사 기록 없음 | 34.47% | 18.18% |

주택 유형별 차이는 `docs/02-SPEC.md` 5.3-1에 있다. 갱신요구권을 행사한 쪽은 네 유형 모두 5% 초과가 1% 미만이다.

## 데이터 출처

| 출처 | 용도 | 이용 조건 |
|---|---|---|
| 국토교통부 전월세 실거래가 (아파트·연립다세대·단독다가구·오피스텔) | 전국 갱신 계약, 갱신요구권과 종전 조건 | 이용허락 제한 없음 |
| 서울시 부동산 전월세가 정보 | 서울 일 단위 갱신, 건물명·지번 | 공공누리 1유형 (출처표시) |

두 출처는 같은 신고 원장에서 나오므로 독립 검증이 아니라 보완 관계로 쓴다.

## 재현

```bash
cp .env.sample .env      # 키를 채운다. .env 는 커밋하지 않는다
set -a; . ./.env; set +a

python3 scripts/quantify_renewal.py --selftest   # 키 없이 동작
python3 scripts/molit_rent.py --selftest         # 키 없이 동작
python3 scripts/quantify_renewal.py <전월세_csv>  # 실제 파일로 계산
```

키가 없어도 자체 검증은 전부 돈다. 공개 파일 데이터는 키 없이 내려받을 수 있고, 일 단위 최신분과 전국 확장에만 키가 필요하다.

## 한계

- 데이터는 신고된 계약의 결과이며 예측이 아니다.
- 서울과 수도권 표본이 가장 두껍다. 그 밖의 지역은 유형에 따라 표본이 얇다.
- 단독·다가구는 원천에 건물명과 지번이 없어 같은 건물끼리 비교할 수 없다.
- 이 서비스는 통계를 보여 주어 의사결정을 돕는다. 법률 자문이 아니다. 개별 계약의 법적 판단은 전문가에게 확인해야 한다.
